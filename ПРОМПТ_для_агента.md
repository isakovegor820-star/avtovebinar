ЗАДАЧА 1. Мерж инфраструктуры + commitlint
═══════════════════════════════════════════════════════════

Ветка `origin/chore/code-hygiene-and-refactor` содержит ESLint, Prettier, Husky, lint-staged и PR-шаблон, но НЕ смержена в main.

1. Смержи: `git merge origin/chore/code-hygiene-and-refactor`
2. Установи commitlint: `npm i -D @commitlint/cli @commitlint/config-conventional`
3. Создай `commitlint.config.cjs`: `module.exports = { extends: ['@commitlint/config-conventional'] };`
4. Создай `.husky/commit-msg` с содержимым: `npx --no -- commitlint --edit ${1}`
5. Убедись что в package.json есть `"prepare": "husky"` в scripts
6. Закоммить: `chore: add commitlint with conventional config`
7. Удали удалённую ветку: `git push origin --delete chore/code-hygiene-and-refactor`

ЗАДАЧА 2. Токены: убрать из URL, перевести на cookie-only
═══════════════════════════════════════════════════════════

СЕЙЧАС: токены передаются через `?token=` в URL (логи, Referer, история браузера).
HttpOnly cookie `aspb_room_token` уже есть, но используется как fallback.
НУЖНО: токен ТОЛЬКО в httpOnly cookie, НИКОГДА в URL.

── Сервер (src/routes/public.ts): ──

a) buildFrontendUrl() — убери параметр token, генерируй URL без ?token=
b) Удали роуты: GET /webinar/timeline/:token и GET /registration/:token
   Оставь только: GET /webinar/timeline/session/current и GET /registration/session/current
c) findRegistrationForRequest(req, token?) — убери параметр token, читай ТОЛЬКО из req.cookies?.aspb_room_token
d) POST /register — убери поле `token` из JSON-ответа (cookie уже ставится через setRoomTokenCookie)
e) sendRegistrationState() — tokenForLinks = null всегда, не включай токен в URL-ы ответа
f) POST-эндпоинты (events, telegram-click, questions, partner-application) — убери чтение токена из req.body, читай из cookie

── Сервер (src/routes/admin.ts): ──

g) В обработчике ручной Telegram-рассылки (~строки 1420-1447): убери roomUrl.searchParams.set('token', accessToken). Ссылка должна быть без токена.

── Клиент (crisis_premium/aspb-api.js): ──

h) Убери: чтение ?token= из URL, переменную token, storage.set/get('crisisPremiumToken')
i) registrationStatePath() → всегда '/registration/session/current'
j) timelinePath() → всегда '/webinar/timeline/session/current'
k) POST-запросы — убери token из body
l) После регистрации — просто window.location.href = result.successUrl (без сохранения токена)
m) В fetch-вызовах убедись что credentials: 'same-origin' (для отправки cookie)

── HTML-страницы: ──

n) crisis_premium/success.html — ссылки на webinar.html БЕЗ ?token=
o) Calendar ICS export — URL без токена

── Миграция (обратная совместимость): ──

p) Добавь middleware в app.ts ПЕРЕД роутами: при наличии ?token= в query →
   1) res.cookie('aspb_room_token', req.query.token, { httpOnly: true, sameSite: 'lax', secure: NODE_ENV==='production', maxAge: ... })
   2) 302 redirect на тот же URL без query-параметра
   Это обеспечит плавный переход для старых ссылок из email/Telegram.

── Тесты: ──

q) tests/core.test.ts и tests/integration.test.ts:
   - Убери передачу токена через URL-path и POST-body
   - Все запросы аутентифицируй через cookie: .set('Cookie', `aspb_room_token=${testToken}`)
   - Добавь тест: запрос без cookie → 401
   - Добавь тест: запрос с невалидной cookie → 401

Коммит: `fix(security): migrate token auth from URL params to httpOnly cookies`

ЗАДАЧА 3. Git-LFS: убрать видео из git
═══════════════════════════════════════════════════════════

Файл crisis_premium/assets/webinar.mp4 (54 МБ) лежит в git как обычный blob. .gitattributes нет.

1. Создай .gitattributes:
   *.mp4 filter=lfs diff=lfs merge=lfs -text
   *.png filter=lfs diff=lfs merge=lfs -text
   *.jpg filter=lfs diff=lfs merge=lfs -text

2. git add .gitattributes && git add crisis_premium/assets/
3. git commit -m "chore(infra): track binary assets via git-lfs"
4. Если допустим force-push: git lfs migrate import --include="crisis_premium/assets/webinar.mp4" --everything
