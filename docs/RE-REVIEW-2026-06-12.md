### Всё ещё присутствуют (5)

**[S1] Живые Telegram-токены в `.env` — НЕ РОТИРОВАНЫ**
`.env:19,25` — те же токены `8654361623:AAF...` и `8839257310:AAE...`. `.gitignore` работает, но секреты на диске не зашифрованы. **Ротировать немедленно через @BotFather.**

**[S2] `ADMIN_DEV_BYPASS` — бэкдор без production-валидации**
`src/routes/admin.ts:66-70` — bypass всё ещё в коде. `validateProductionSecurity()` НЕ проверяет `ADMIN_DEV_BYPASS`. При `NODE_ENV=development` на проде — полный owner-доступ.

**[S3] Admin-сессия без server-side revocation**
`src/lib/tokens.ts:33-72` — stateless HMAC-cookie. Смена `ADMIN_LOGIN` инвалидирует ВСЕ сессии. Нет session table, нет revocation list.

**[R3] Advisory lock на pooled-соединении**
`src/lib/reminders.ts:332-348` — `pg_try_advisory_lock()` (session-level) на pooled-коннекте. Блокировка переживает транзакцию. **Заменить на `pg_try_advisory_xact_lock()`.**

**[P1] N+1 в reminders — частично исправлено**
`src/lib/reminders.ts:171` — cursor pagination добавлена, но ВНУТРИ цикла — отдельный `emailOutboxJob.count()` на каждую регистрацию. До 5000 лишних round-trip.

## 💡 НОВЫЕ ПРОБЛЕМЫ (от 23 коммитов)

### HIGH (3)

**[NEW-H1] Staging deploy билдит только `api`, НЕ `webinar-worker`**
`ci.yml:170` — `docker compose build api`. Worker остаётся на старой image. Изменения в worker-коде НЕ деплоятся.
**Fix**: `docker compose build` (без фильтра) или `build api webinar-worker`.

**[NEW-H2] Daily broadcast news job без distributed lock**
`telegramNews.ts:272-283` — In-process boolean guard вместо PostgreSQL advisory lock. Два инстанса запустят job одновременно. `slotKey` unique constraint спасает от дупликатов, но не от wasted work.
**Fix**: Использовать тот же advisory lock pattern что в `reminders.ts`.

**[NEW-H3] Дублированные ES module instances от cache-buster query strings**
`main.js:5-18` — `video.js` импортирует `registration.js` (bare), а `main.js` — `registration.js?v=account-access-18`. Браузер считает их разными модулями. `renderedInsightTimes` Set НЕ шарится между instances.
**Fix**: Унифицировать import paths. Использовать build tool для cache-busting.
