# Производственный пакет автовебинара АСПБ

Цель пакета: подготовить запись автовебинара так, чтобы она работала не как обычное видео, а как управляемый автоэфир на платформе АСПБ.

Что внутри:

- `01-blueprint.md` — как строится качественный автовебинар и какая логика нужна именно для АСПБ.
- `02-script-v1.md` — сценарий первой версии видео на 55-60 минут.
- `03-recording-brief-for-vasily.md` — ТЗ для Василия: как записывать, какие блоки, что нельзя говорить, какие отдельные ответы доснять.
- `04-platform-upload-and-qa.md` — как загрузить видео на платформу, связать с таймлайном и протестировать.
- `timeline-events.json` — карта событий для платформы: таймкоды, сообщения, CTA.

Рабочая модель:

1. Записываем основной вебинар одним чистым видео `webinar.mp4`.
2. Отдельно записываем короткие ответы на частые вопросы, чтобы потом использовать их как вставки, отдельные клипы или базу для чат-сценария.
3. Кладем `webinar.mp4` в `crisis_premium/assets/webinar.mp4`.
4. Синхронизируем таймлайн с записью.
5. Проверяем комнату по token-ссылке на desktop/mobile.
6. Показываем демо команде и вносим правки в 2-3 итерации.

Главное правило: автовебинар не должен ощущаться как "запись из архива". Он должен ощущаться как запланированный эфир: с началом, логикой, подсказками, вопросами, CTA и финальным действием.
